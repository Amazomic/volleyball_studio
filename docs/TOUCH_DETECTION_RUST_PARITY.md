# CPU-касания: траектория мяча и геометрия игрока

Кандидаты касаний рассчитываются по непрерывности траектории VBallNet, гравитационно скорректированным изменениям скорости и направления мяча, а также близости к рамкам и точкам тела игроков из RF-DETR/RTMPose.

Точки касания — предварительные события. Их тип не должен назначаться без соответствующего движения тела и мяча. Ложные скачки мяча, исчезновение наблюдений и недостаточное подтверждение позы не создают авторитетных действий.

Основная реализация: `rust/volley-core/src/touch_pipeline.rs`, `rust/volley-core/src/touch_pipeline/geometry.rs`, `rust/volley-core/src/touch_pipeline/pose_motion.rs`, `rust/volley-app/src/cpu_touches.rs`. CPU-пересчёт работает с сохранёнными GPU-артефактами и создаёт отдельную неизменяемую версию.

Проверка: `cargo test --workspace --offline --locked`, `cargo clippy --workspace --all-targets --offline --locked -- -D warnings`. Качество на реальных матчах и экспорт требуют отдельных проверок.
