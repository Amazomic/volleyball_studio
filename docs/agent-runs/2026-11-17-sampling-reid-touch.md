# 2026-11-17 — шаг игроков 1, ReID по наблюдениям, строгие Touch

## Изменения
- Первичный анализ: частота детекции RF-DETR + RTMPose по умолчанию каждый кадр (1 / 30 FPS); параметр `studio-gpu-person-stride` остаётся в основных настройках GPU. Изменение шага входит в ключ GPU-кэша.
- Исправлена автоподсказка ReID от подтверждённых треков: совпадение временных диапазонов само по себе не означает одновременную видимость. Используются измеренные `visible_spans` и проверки пространственных дубликатов.
- Новые Studio CPU-профили используют `TouchAlgorithm::PoseMotion`; непосредственно сохранённые / старые `TouchSettings` остаются `Legacy`. Для строгого режима обязательны сохранённые позы; старые анализы не переписываются.
- Русская/английская локализация, WASM и регрессионные тесты обновлены.

- Ручные подтверждённые привязки и пользовательские видео не изменялись.
