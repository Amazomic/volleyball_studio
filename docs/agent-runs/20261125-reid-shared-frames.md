## Data flow and limits

The existing early rally worker builds its validated stable track plan before the full-resolution original RGB decoder reaches that rally. Use the same SHA-checked track index to choose the best measured frame plus the bounded existing photo candidates for the rally and full work window. Interpolated observations are excluded by the canonical index. The worker crops only selected frames as the existing RTMPose decoder produces them, without opening another video or changing the RTMPose inputs. Crop geometry uses the same existing padded crop_box helper. Resizing to the model's 128x256 BGR input is done only after original-resolution cropping, with separable antialiased bilinear resampling and no JPEG or prepared low-resolution video. Exact source path, size/mtime, analysis start offset, local frame number and integer crop must all match a downstream verified request. The buffer belongs to one full pipeline invocation and contains at most 1365 crops (128 MiB pixel budget), not whole frames or entire rallies. It is not captured for GPU-only runs. It is released when the pipeline ends.

Both the first track embedding and independent photo comparisons use the buffer; missing crops (e.g. final scope differs, buffer limit, legacy CPU-only reprocessing, cached GPU results, no early pose decoder) keep the existing verified seek/decode path. No fabricated frames. The input preprocessing differs slightly from FFmpeg's direct YUV crop and resize, which may round odd crop coordinates to chroma alignment. Existing compatible cached embeddings remain valid for the same model and frame/crop; new persisted crop provenance records shared_rgb, default false for historical entries. Separate in-memory cache keys distinguish the shared RGB and legacy seek inputs. No reference-album cache/model fingerprint change and no forced re-encoding of all saved reference photos. The status records reid_shared_crops (bound, captured, hits, misses, pixel bytes and capacity); hits/misses are lookup counts, not elapsed time or identity confidence.
