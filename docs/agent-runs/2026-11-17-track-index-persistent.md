# 2026-11-17 — Постоянный индекс Track ID

Ветка: `codex/20261117-track-index-persistent`, база `e36aa085d27d`.

- После записи immutable CPU-replay рассчитывается и сохраняется проверенный полный индекс Track ID в отдельном каталоге производных данных `native_track_indices/<replay_id>/full.json`.
- После записи версии розыгрышей сразу готовится её отдельный индекс `rally-<sha256>.json` с фактически наблюдавшимися ID в интервалах игры. Веса моделей и исходные GPU/CPU файлы не меняются.
- При чтении сначала проверяется постоянный индекс по SHA источника, версии, числу кадров, размеру, времени модификации и файловому change-stamp. При отсутствии, повреждении либо изменении исходника выполняется исходная полная SHA-верификация со сканированием и перепостроением.
- Одновременные запросы одного replay сериализуются, другие видео не блокируются.
- Уточнены сообщения интерфейса: при открытии загружается готовый индекс, а не запускается повторная обработка видео.
- Обратная совместимость: ранее сохранённые анализы получают индекс лениво при первом открытии.

Проверено: `cargo fmt --all -- --check`; `cargo test -p volley-app --locked --offline` (332 passed, 9 ignored); тест на перезапуск кэша, повреждение сохранённого индекса и изменение источника; `test_studio_wasm_ui.mjs`, `test_volley_web_wasm.mjs`, ownership, roadmap.
