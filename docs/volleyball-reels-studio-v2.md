# Volleyball Studio — монтаж и анализ

Для актуальной реализации используйте `docs/volleyball-reels-studio.md` и `docs/RUST_ARCHITECTURE.md`.

Поддерживаемые нейросети: VBallNet V4c (мяч), RF-DETR Medium (игроки), RTMPose (поза). Монтаж работает по сохранённым версиям розыгрышей и касаний, используя оригинальный видеопоток.
