# Volleyball Studio — руководство по интерфейсу

Проверено по исходному коду `70159494` (27.11.2026). [Запуск](RUST_DEPLOYMENT.md) · [Архитектура](RUST_ARCHITECTURE.md) · [Документация](README.md).

## Рабочий процесс

1. Создайте или выберите проект, добавьте одно или несколько видео. На вкладке анализа задайте диапазон и разметку площадки/сетки; исходные записи не изменяются.
2. Запустите анализ. В первой фазе мяч, стабилизация и первичные игровые интервалы/касания определяют область обработки игроков; RF-DETR, трекинг и RTMPose дают наблюдения. Вторая фаза уточняет события и публикует розыгрыши. GPU-свидетельства переиспользуются в совместимых CPU-пересчётах.
3. В предпросмотре выбирайте розыгрыши, перемещайтесь по шкале и проверяйте траекторию, скелеты, площадку и типы касаний. Используйте переключатели слоёв; режим после Ball Stabilizer показывает траекторию детектора касаний.
4. На вкладке «Игроки» проверяйте Track ID и привязки к спортсменам. ReID предлагает соответствия, но не заменяет проверку личности.
5. В «Отчёте» изучайте статистику по сохранённому анализу; в «Монтаже» выбирайте фрагменты и экспортируйте видео из оригиналов.

## Вкладки

| Вкладка | Назначение |
|---|---|
| Игроки | Состав, фотографии, треки, сравнение признаков, подтверждение привязок |
| Анализ | Видео, разметка, настройки двух фаз, стадии, очередь и история выбранного проекта |
| Предпросмотр | Видео и слои разметки, шкала времени, карточки розыгрышей, проверка касаний |
| Отчёт | Статистика игроков и розыгрышей |
| Монтаж | Избранные розыгрыши, рилс игрока, лучшие атаки, лучшие и длинные розыгрыши, творчество |

Quick Reel открывается отдельной кнопкой и выполняет самостоятельный анализ; не подменяет сохранённый анализ проекта. Связь выбора проекта и версий описана в [RUST_HEADER_CHAIN.md](RUST_HEADER_CHAIN.md).

## Настройки анализа

RF-DETR по умолчанию измеряет каждый кадр. RTMPose — каждый кадр около касания и каждый десятый для остальных игроков. Эти значения относятся к шкале 30 FPS; сохранённый профиль может отличаться. GPU CUDA используется для основных моделей; ReID допускает Auto/GPU/CPU. Auto использует GPU для подходящих пакетов и CPU для малых или при недоступности CUDA. Изменение устройства не требует уничтожения сохранённых признаков.

## Монтаж

«Творчество» позволяет отбирать розыгрыши, избранное, касания (с фильтрами типа и игрока) или ручные фрагменты и упорядочивать их. Аудиодорожка для обычного монтажа необязательна. Готовые видео доступны в библиотеке: кнопка воспроизведения открывает плеер и начинает воспроизведение, пробел переключает паузу/воспроизведение. Ограничения браузера могут потребовать взаимодействия с плеером.

Для автоматизации используйте [Agent API](../.agents/skills/volleyball-reels-studio/references/agent-api.md), а не устаревшие Python-команды.
