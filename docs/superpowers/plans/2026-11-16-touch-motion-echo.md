# Подавление повторного пика касания

Цель: участок 7,83–7,97 с должен давать одно касание при отсутствии независимого второго контакта.

Причина: короткий пропуск мяча растягивает окно оценки скорости через предыдущий удар. Слабый пик после разворота проходит минимальный временной интервал и получает другой Track ID.

- [x] Воспроизвести двойное событие 235/239 на полной изолированной копии CPU-replay с сохранёнными позами. Переносимые тесты финального отбора падают без подавления эха и проходят с ним.
- [x] В существующем `rust/volley-core/src/touch_pipeline.rs` определить слабое эхо соседнего разворота в пределах окна оценки скорости. Независимый контакт по телу, отдельный резкий разворот и удалённое по времени событие не подавлять.
- [x] Применить правило к потоковой дедупликации после уточнения поз, включая границу блоков. Обновить версию CPU-метода и проверку совместимости в `studio_pipeline.rs` до v9.
- [x] Проверить регрессию, сохранение самостоятельных небольших поворотов и быстрых последовательных касаний, полный Rust-набор, форматирование, WASM, ownership/roadmap. Прежние ошибки перечислены в журнале миграции.
- [x] Собрать release; записать результаты проверки в журнал миграции.
- [ ] Применить сборку к работающей Studio и пересчитать CPU-результат. Перезапуск запрещён активной `video_preparation`; исходное видео и активную задачу не прерывать.

GPU-данные, старые CPU-результаты и ручные решения неизменяемы. Для проверки реального фрагмента использовать отдельные диагностические выходы; новый рабочий CPU-анализ публиковать отдельной версией без повторного GPU-инференса.
