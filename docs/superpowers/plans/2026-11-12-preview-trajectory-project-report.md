# Траектория мяча и отчёт проекта

В предпросмотре разделять сырые VBallNet-наблюдения и восстановленную траекторию. Границы розыгрышей определять по движению мяча, после чего показывать игроков RF-DETR и RTMPose только в нужных отрезках.

Сводный отчёт привязывать к выбранной версии анализа и источникам событий, не смешивать данные от разных запусков.
