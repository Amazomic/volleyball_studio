# Перенос интерполяции в CPU-профиль

Цель: параметры interpolate_players и interpolate_pose принадлежат post, первичный анализ сохраняет только измерения.

Архитектура: существующий studio_pipeline остаётся владельцем профилей. Адаптер чтения переносит старые gpu-поля в post, явные post-поля имеют приоритет. Сохранённые результаты не переписываются. GPU-совместимость не зависит от интерполяции; CPU-совместимость учитывает обе настройки и фактический манифест трекинга.

Файлы: studio_pipeline.rs, pose_inference.rs, pose_inference/stream.rs и существующие тесты, studio_tabs.js и браузерные проверки профилей. DOM ID сохраняются для восстановления уже сохранённых настроек формы.
