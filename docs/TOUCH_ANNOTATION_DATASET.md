# Дообучение: один таймлайн и расчёт касаний по траектории

## Сценарий

1. Выбрать проект, исходное видео, CPU-версию и «Дообучение».
2. Выбрать «По траектории мяча». Переключатель «Скрыть неактуальные данные» убирает игрока, позы, CPU-касания, остальные слои. При выключении возвращает их.
3. Нажать «Рассчитать касания». Rust анализирует только сохранённую траекторию VBallNet из SHA-проверенного CPU replay (не RF-DETR, не RTMPose).
4. Жёлтые метки — предсказания; зелёные на единой шкале обработанного предпросмотра — редактируемые касания. Их можно добавлять, удалять, переносить перетаскиванием или стрелками по одному кадру.
5. Исправлять начала и концы розыгрышей; список содержит три видимые строки и собственную прокрутку. Дополнительных временных шкал в дообучении нет.
6. «Сохранить данные касаний» атомарно записывает черновик и достоверные признаки физических кандидатов. Пока нет сохранения — никакого изменения модели или серверных меток.
7. Повторно «Рассчитать касания» — калибровка порога силы отклонения и сдвига времени ±2 кадра по сохранённым исправлениям, затем новые физические предсказания.
8. «Завершить проверку видео» подтверждает только сохранённую разметку. При правках подтверждение сбрасывается.

Когда есть сохранённые метки, новый расчёт не заменяет эталон. Кнопка «Взять результат расчёта для правок» заменяет только черновик с подтверждением.

## Источник и файлы

- Неизменяемый трек: native_cpu_replays/<replay_id>/tracked_frames.jsonl; SHA-256 перепроверяется при извлечении.
- Физический детектор: volley-core/src/motion/trajectory.rs — trajectory_breaks и ball_motion_extrema.
- Ручная разметка: <data_root>/training/touch_annotations.json. Атомарное сохранение, source SHA, optimistic revision, запрет смешивания видео/CPU-версий.
- API: GET/POST /api/training/annotations (action=save) и POST /api/training/trajectory/calculate.
- rust/volley-app/src/touch_annotation.rs — метки и сохранение
- rust/volley-app/src/touch_annotation/trajectory.rs — калибровка и API
- rust/volley-app/src/native_player_tracks/trajectory.rs — SHA-проверенный scan VBallNet
- rust/volley-app/src/main.rs — маршруты
- rust/volley-app/static/studio.js, studio.html, studio.css — единая шкала и управление

## Проверка качества

Автоматическая CPU-версия и новый расчёт по траектории сравниваются с сохранённым эталоном (TP/FP/FN/F1, ±1 кадр).
В итоговую статистику включаются только явно проверенные видео. Калибровка по сохранённым примерам — не независимая валидация.
Для объективного теста требуется отложенное видео; дообучение весов нейросетей НЕ выполняется, корректируется физический детектор.
