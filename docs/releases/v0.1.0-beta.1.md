# Volleyball Studio v0.1.0-beta.1

**19 ноября 2026 · публичная бета / public pre-release. Не production-ready.**

Первая помеченная beta-версия Rust-native Volleyball Studio. Сборки предназначены для локальной оценки функциональности и сбора обратной связи, **не для обработки единственных копий ценных материалов**.

## Что вошло / Highlights

- Rust-native Studio: проекты, воспроизведение исходных видео, первичный анализ и версионированная CPU-постобработка; поддержка VBallNet, RF-DETR, RTMPose через внешние модели и совместимые среды исполнения.
- Разметка розыгрышей и касаний по траектории мяча, сравнение с CPU-результатом, ручной эталон на единой временной шкале.
- В «Дообучении» цикл: рассчитать касания → взять результат для правок → поправить метки → явно сохранить → пересчитать. Подбор порога и временного сдвига использует размеченные видео, включая ранее подтверждённые метки без повторной записи.
- Просмотр/проверка Track ID, галерея игроков, инструменты ручного подтверждения, монтаж из оригинала и библиотека подготовленных видео.
- Безопасный запуск только на localhost, версионирование источников с SHA-256, защита от противоречивых ревизий и независимое хранение ручной разметки.

## Пакеты / Downloads

- Windows x64: архив beta-сборки с нативным volley-app.exe, лицензией и локальным запуском.
- Linux x86-64 / WSL2: архив beta-сборки с ELF и локальным запуском. Собран в Ubuntu 25.04 с glibc 2.41; совместимость со старыми дистрибутивами не гарантируется.
- Автоматически доступен исходный код по тегу версии.

Архивы включают **приложение и встроенный Rust/WASM интерфейс**, но **не** включают веса моделей, исходные видео, FFmpeg/FFprobe, ONNX Runtime/CUDA/cuDNN или пользовательские данные. Для анализа нужны совместимые внешние библиотеки, модели и аппаратное ускорение. Пакеты проверяются отдельно от исходного проекта; README внутри архива объясняет запуск.

## Ограничения / Known limitations

- Статус runtime: production_ready=false. Это не финальная миграция и не замена сохранённому Python-чекпойнту.
- Точность распознавания на независимых полных матчах, производительность GPU и экспорт MP4 не прошли отдельную приёмку в рамках этого бета-релиза.
- Сравнение и калибровка по размеченным обучающим видео не равнозначны независимой валидации качества; веса TCN при сохранении меток не переобучаются.
- Нельзя открывать локальный API в Интернет: доступ только с 127.0.0.1. Не запускайте два экземпляра Studio в одном репозитории/на одном порту.
- Для Linux-сборки может потребоваться glibc не ниже версии окружения сборки; бинарник не является статически связанным.
- Старые проекты и модели требуют собственных файлов на диске; при их отсутствии функции инференса недоступны.

## Проверки / Verification

Проверки полной Rust/Node/WASM CI и отдельные smoke-запуски локального beta-бинарника выполняются перед публикацией. Статус проверок и SHA-256 архивов публикуются вместе с GitHub Release; не делайте вывод о проверке GPU, моделей или MP4 по успешной загрузке UI.
