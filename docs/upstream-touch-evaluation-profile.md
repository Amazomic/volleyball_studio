# Исторический профиль сравнения касаний (04.11.2026)

Этот экспериментальный профиль больше не входит в доступные варианты первичного анализа. Для новых запусков используется единственный поддерживаемый путь VBallNet V4c → RF-DETR Medium → RTMPose и CPU-вычисление касаний по траектории мяча и ключевым точкам тела.

Новые эксперименты по качеству следует сравнивать на одинаковых исходных видео и временных диапазонах. Существующие пользовательские проекты и архивы анализов не удаляются автоматически.
