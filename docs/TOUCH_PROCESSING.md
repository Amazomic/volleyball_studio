# Расчёт касаний в Rust

Основной источник мяча — VBallNet V4c. RF-DETR Medium выдаёт рамки игроков; RTMPose рассчитывает точки тела на исходных кадрах. Траектория мяча сначала определяет границы розыгрышей, после чего в них выполняется анализ игроков и поз.

## Кандидаты касаний

`rust/volley-core/src/touch_pipeline.rs` организует вычисление по существующим GPU-наблюдениям. `geometry.rs` проверяет гравитационно скорректированное изменение скорости и направления мяча и близость к наблюдаемому игроку. `pose_motion.rs` сопоставляет наблюдения COCO17 по времени. Для поиска при отсутствии мяча используются только ограниченные и проверенные интервалы; интерполяция не подменяет реальные наблюдения при подтверждении.

Существуют режимы `legacy` (физические изменения движения + геометрия игрока), `pose_motion` и экспериментальный `trajectory_tcn`. Ни один из них не использует отдельную модель касаний. При недостаточном подтверждении тип остаётся неизвестным.

## Обработка результатов

- `rust/volley-app/src/cpu_touches.rs` сопоставляет кандидаты с временными Track ID и сохраняет версионированные CPU-артефакты.
- `rust/volley-app/src/cpu_rallies.rs` выполняет обработку розыгрышей.
- Повторная CPU-постобработка не переписывает исходные GPU-данные.
- Сохранённые Track ID не считаются подтверждёнными игроками; детали определяются при наличии надёжных наблюдений тела.

Требуется отдельная проверка точности на размеченных реальных матчах; успех синтетических тестов сам по себе не подтверждает качество распознавания.
