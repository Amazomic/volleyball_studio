# GPU-инференс и CPU-постобработка

Текущий путь первичного анализа работает в Rust (`rust/Cargo.toml`).

1. Проверяется оригинальное видео, выбранные начало и конец.
2. VBallNet V4c определяет положения мяча на разрешённых участках.
3. Из траектории мяча рассчитываются розыгрыши.
4. RF-DETR Medium обрабатывает игроков только в пределах розыгрышей.
5. RTMPose использует рамки RF-DETR и исходные пиксели для оценки точек тела.
6. CPU-просчёт восстанавливает треки игроков, классифицирует кандидаты касаний и готовит отображаемые версии событий.

Переобработка CPU использует ранее сохранённые и проверенные по SHA-256 исходные наблюдения. Пороги и режимы касаний сохраняются в настройках конкретного CPU запуска. Новые GPU-сессии для смены порогов не требуются, если необходимые наблюдения уже записаны.

Исполняемые части: `rust/volley-app/src/studio_pipeline.rs`, `rust/volley-app/src/inference_fusion.rs`, `rust/volley-app/src/cpu_touches.rs`, `rust/volley-app/src/cpu_rallies.rs`.
