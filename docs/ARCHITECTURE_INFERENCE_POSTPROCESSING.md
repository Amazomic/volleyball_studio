# Архитектура анализа и постобработки

Последовательность исполнения первичного анализа:

```text
Оригинальное видео + диапазоны анализа
    → VBallNet V4c (траектория мяча)
    → выделение розыгрышей по движению мяча
    → RF-DETR Medium (рамки игроков только на розыгрышах)
    → RTMPose (COCO17 на исходных пикселях)
    → проверенное объединение GPU-наблюдений
    → CPU-треки / касания / типы действий
    → предпросмотр, статистика, монтаж
```

Объединённые GPU-наблюдения не содержат подтверждённых личностей или касаний. Треки игроков предварительные; окончательные события и их типы требуют проверки источников. Оригинальное видео не подменяется подготовленным прокси при монтаже.
